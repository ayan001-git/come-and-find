# Come and Find — исправление голосового ввода

Изменены только четыре файла веб-интерфейса:
- web/voice.js — немедленная реакция на кнопку, диагностика ошибок, таймаут, распознанный текст.
- web/index.html — заметный блок состояния и обновлённый адрес скрипта для сброса кеша.
- web/styles.css — оформление сообщений об успехе и ошибках.
- web/app.js — запросы к API больше не отключают кнопку голосового ввода.

Go backend, SQL, аккаунты, корзина и заказы не менялись.

## Как применить
1. Сохрани копию своей папки come-and-find.
2. Распакуй патч в папку come-and-find с заменой файлов (с сохранением структуры web/).
3. В терминале VS Code останови Docker Ctrl+C, если он ещё работает.
4. Выполни docker compose up --build.
5. Открой http://localhost:8080 в Chrome и нажми Ctrl+Shift+R.
6. Прокрути до Catalogue, выбери русский язык, нажми Voice input.
7. Прочитай сообщение под кнопкой, разреши микрофон и произнеси запрос.
8. Проверь распознанный текст и нажми Search.

## Если не работает
- Microphone permission denied: разреши микрофон для localhost в настройках Chrome и перезагрузи страницу.
- Voice input is unavailable: используй современный Chrome или Edge, localhost либо HTTPS.
- network error: проверь интернет, браузерный сервис распознавания может быть недоступен.
- No working microphone: проверь устройство ввода и настройки Windows > Конфиденциальность и безопасность > Микрофон.
- timed out: сервис распознавания не ответил за 15 секунд, попробуй другой браузер или текстовый поиск.

Код проверен на синтаксис и на семи сценариях с имитацией браузерного SpeechRecognition.
Реальный микрофон и сервис распознавания на компьютере пользователя ещё не проверены.
