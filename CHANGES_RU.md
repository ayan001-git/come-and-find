# Изменения исправленной версии

1. Одна папка проекта, без вложенных копий и чужой истории Git.
2. POST корзины прибавляет количество; PATCH устанавливает его; интерфейс +/−.
3. Проверка количества, остатка и принадлежности товаров одному поставщику.
4. Checkout проверяет все позиции, включая снятые с публикации. Ошибка не
   удаляет корзину и не оставляет частичного заказа.
5. Только последовательные статусы: paid -> processing -> shipped -> delivered.
6. Запрещено изменять заказы другого поставщика.
7. Фильтры минимальной/максимальной цены, проверка границ, сброс фильтров.
8. Администратор снимает/одобряет публикации, активирует/деактивирует
   обычных пользователей и последовательно изменяет статусы оплаченных заказов.
9. Отключённый пользователь теряет доступ через существующую сессию.
10. Обработаны ошибки чтения БД, создания сессии, недопустимые методы и JSON.
11. Проверка email, ограничение пароля в байтах для bcrypt, проверка категории
    и локального пути изображения товара.
12. Блокирование повторных UI-действий, ошибки async, очистка состояния при выходе,
    обновление каталога после действий, адаптивные стили и доступный focus.
13. На новой базе 12 товаров, 3 синтетических поставщика и 5 категорий.
14. Docker копирует go.sum; run.ps1 не затирает существующий DATABASE_URL.
15. Обновлены учебные PDF; добавлены инструкции и воспроизводимые тесты.

Заметки: Reject оставляет публикацию скрытой без отдельной причины отказа.
Остаток уменьшается при создании заказа до симуляции оплаты; резервирование с
истечением времени и отмена с возвратом остатка не реализованы и не входят в
этот MVP. Не используй демонстрационные аккаунты для реальных продаж.

Сначала прочитай README.md, затем docs/DEFENSE_START_RU.md.
Английские отчёты остаются черновиками до подтверждения группы, ролей,
самооценки, сроков и реальных записей grooming/planning poker.

16. Голосовой ввод с проверкой текста, остановкой, выбором языка и резервным вводом.
17. Правила умного поиска по RU/EN категориям, признакам и цене; API интерпретации.
18. Учтено замечание преподавателя в TSIS 4-7, группа 21; обновлены SP и риски.
